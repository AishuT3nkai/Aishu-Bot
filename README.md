# Aishu Bot

A multilingual Discord bot built for Aishu.

## Languages

- Indonesia
- Tagalog
- English

## Current commands

- `/introduce` — opens a form for Name, Date of birth, Age, Origin, and City.
- `/language` — server managers can choose the server language.

## Setup

1. Install Python 3.10+.
2. Install dependencies with `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env`.
4. Put your Discord bot token in `.env`.
5. Run `python bot.py`.

Never commit `.env` or your Discord bot token.
